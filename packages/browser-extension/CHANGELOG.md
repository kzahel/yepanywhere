# Chrome extension changelog

## Unreleased

- Load local HTML artifacts and neighboring images through the isolated managed
  viewer over the encrypted relay, without additional extension permissions.

## [0.1.4] - 2026-10-24

- Refresh the bundled client for Yep Anywhere 0.11.0, including cached ticket
  description search and existing-folder project setup on supported servers.
- Improve composer focus, draft handling, session navigation and provider controls.
- Update client dependencies for published security advisories.
- Preserve the existing store identity, install permissions and saved-host login.

## [0.1.3] - 2026-10-14

- Open the app in popup windows and from the toolbar context menu.
- Start sessions in a dedicated window and show a session's issues in the side panel.
- Remember collapsed side-panel groups and new-session defaults.
- Fix queued-message recall, attachment draft synchronization and production diagnostics.

## [0.1.1] - 2026-10-13

- Initial public client, side panel, related-session lookup and optional site badges.
